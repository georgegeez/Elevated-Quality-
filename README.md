# Elevated Quality Website

Static lead-generation website for Elevated Quality.

## Files
- `index.html` — page content
- `styles.css` — responsive design
- `script.js` — mobile navigation and footer year

## Before deploying
1. Open `index.html`.
2. Find `YOUR-EMAIL-HERE`.
3. Replace it with the email address that should receive quote requests.
4. Optionally replace the FormSubmit form action with your own backend/form service.

## Deploy on Render
1. Put these files in a GitHub repository.
2. In Render, create a **Static Site**.
3. Connect the GitHub repository.
4. Build command: leave blank.
5. Publish directory: `.`

The site is mobile responsive and requires no build step.
